# Icon sources

- Flutter, Dart, Firebase, React, JavaScript, TypeScript, HTML5, CSS3, MySQL, Git, GitHub, Postman, Vercel, Android Studio and VS Code: https://github.com/devicons/devicon (MIT).
- AdMob: https://github.com/simple-icons/simple-icons (CC0).
- Riverpod: https://github.com/rrousselGit/riverpod/blob/master/website/static/img/logo.svg (project logo).
- Flame: https://github.com/flame-engine/flame/blob/main/doc/_sphinx/images/logo_flame.png (project logo). The widget displays the flame portion using a cover crop.
- FlutterFlow: https://www.flutterflow.io/apple-touch-icon.png (official website icon).
- Google Play Games: https://www.gstatic.com/images/branding/product/2x/play_games_48dp.png (official product icon).

Marks identify their respective technologies. REST APIs and SQL use generic API/database symbols; Provider uses a state-tree symbol. No distinct Provider brand logo is claimed.
